## Seam

The shared concern: nothing about agents repeals the older lessons; in fact agents amplify them. These concepts collect the **foundational moves** that pay double in agent work — shared vocabulary (DDD), workflow-first thinking before reaching for an agent, zooming out before diving in, and ADRs to anchor decisions. (Deep modules itself lives in `agent-skill-design` because that's where it's load-bearing here.)

## Members

- **pre-ai-fundamentals** — reading-list mapping classic SWE books onto AI workflows.
- **ubiquitous-language** — DDD's shared glossary; the role CONTEXT.md plays for both humans and agents.
- **workflow-before-agents** — climb the complexity ladder; don't reach for an agent when a workflow suffices.
- **zoom-out** — start unfamiliar code with a glossary/map pass before edits.
- **adr-discipline** — record decisions sparingly so future agents know what's load-bearing.
