## Summary
Run every incoming issue through a small canonical state machine — two category roles (`bug`, `enhancement`) and five state roles (`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`) — so AFK agents only ever pick from a fully-specified queue.

## Why it matters
Agent-driven implementation depends on issues being unambiguously ready. Without an explicit triage state, agents grab half-specified work, ask follow-up questions in PR comments, and waste cycles. A canonical state machine forces every issue into one of five clearly-defined buckets and surfaces exactly which subset the night-shift loop can consume. It also creates a durable place to record reproduction attempts, agent briefs, and `wontfix` rationale — preventing the same enhancement from being re-litigated next quarter.

## How to apply
- Adopt the seven canonical roles (mapped to whatever label strings your tracker uses).
- Every issue carries exactly one category role and one state role.
- Default flow: unlabeled → `needs-triage` → (`needs-info` ↔ `needs-triage`) → `ready-for-agent` | `ready-for-human` | `wontfix`.
- Every comment posted by an AI during triage starts with a disclaimer (`> *This was generated by AI during triage.*`).
- For bugs, **attempt reproduction before grilling**. A confirmed repro becomes the agent brief; failure to repro is a strong `needs-info` signal.
- `ready-for-agent` posts a structured agent brief. `ready-for-human` uses the same structure but notes why it can't be delegated (judgment, external access, manual testing).
- `needs-info` writes triage notes capturing what's been established so future re-triage doesn't re-ask.
- `wontfix` for enhancements writes to a durable `.out-of-scope/<slug>.md` and links from the closing comment, so future triage can spot duplicates.

## Caveats
- Roles must map to real label strings on the tracker. Pocock's `/setup-matt-pocock-skills` does this once per repo.
- The state machine assumes a maintainer in the loop. Fully autonomous triage isn't supported by design.
